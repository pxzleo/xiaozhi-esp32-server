# 网易云音乐播放功能

## 功能范围

网易云音乐以独立服务端插件提供，与“服务器音乐播放”和“HomeAssistant 音乐播放”互斥选择。

未登录网易云账号时，只允许按歌名或随机播放 `fee == 0` 的完全免费歌曲及 `fee == 8` 的非会员可在线播放歌曲。插件不会播放试听片段，也不会调用解灰或替换音源能力；即使外部 API 错误开启全局解灰，插件也会拒绝非网易云域名返回的替换音源。

在管理端扫码登录后，可以通过语音：

- 按歌曲名播放账号当前拥有播放权益的歌曲，包括有效 VIP 权益覆盖的歌曲；
- 播放指定的用户歌单；
- 播放每日推荐；
- 播放私人 FM；
- 随机播放每日推荐。
- 在当前播放队列中切换上一首或下一首；
- 暂停、继续或停止当前播放。

歌单、每日推荐和私人 FM 单次加入播放队列的歌曲数由 `max_tracks` 控制，默认 20，最大 50。
播放器独立保存曲目列表，每次只向 TTS 队列调度当前曲目，当前曲目播放完成后再调度下一首。语音指令打断音频缓冲时，已保存的曲目列表不会丢失。由于当前设备协议不回传精确播放进度，“继续播放”会从当前歌曲开头重新播放。

## 外部服务

本功能依赖自建的 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced)。它是非官方接口，可能因网易云接口变化、账号风控、地区或版权限制而失效，不适合作为具有稳定性承诺的商业音乐接口。

建议仅在可信网络中部署，并明确关闭解灰功能：

```bash
docker run -d \
  --name netease-music-api \
  -p 3000:3000 \
  -e ENABLE_GENERAL_UNBLOCK=false \
  -e ENABLE_FLAC=false \
  moefurina/ncm-api:latest
```

`api_base_url` 使用 `http://127.0.0.1:3000` 或 `http://localhost:3000` 时，小智服务端会直接访问本机网易云 API，管理浏览器的扫码请求则自动通过已登录的 manager-api 同源转发。这样从其他电脑打开智控台时无需暴露 3000 端口，也不会错误访问客户端自己的回环地址。该转发只开放生成密钥、生成二维码、查询扫码状态和读取账号四个登录接口。

如果配置的是非回环地址，管理浏览器会直接访问该地址，因此远程网易云 API 仍需允许浏览器跨域访问；智控台使用 HTTPS 时，该 API 也应使用 HTTPS，避免浏览器拦截混合内容请求。

## 管理端配置

在智能体的“功能管理”中选择“网易云音乐播放”。选择后会自动取消另外两种音乐播放器。

主要参数：

- `api_base_url`：NeteaseCloudMusicApiEnhanced 地址；与小智服务部署在同一台机器时推荐使用 `http://127.0.0.1:3000`；
- `quality`：`standard`、`higher`、`exhigh`、`lossless` 或 `hires`；
- `max_tracks`：歌单类请求单次最多加入队列的歌曲数；
- `prepare_timeout_seconds`：从查询歌单到音频准备完成的总时间，默认 20 秒、最大 25 秒，确保不会超过服务端默认 30 秒工具调用超时；
- `cache_size_mb`：服务端音乐缓存容量；
- `cache_ttl_hours`：缓存有效期。

点击“扫码登录网易云”，使用网易云音乐 App 扫码并确认。扫码获得的 Cookie 作为隐藏插件参数保存，不会显示在配置表单、工具描述或普通日志中。清除登录后立即回到匿名播放限制。

## 语音示例

- “播放周杰伦的晴天”
- “播放我的歌单民谣收藏”
- “播放网易云每日推荐”
- “打开我的私人 FM”
- “随机放一首歌”
- “下一首” / “上一首”
- “暂停播放” / “继续播放” / “停止播放”

未登录时调用歌单、每日推荐或私人 FM，会明确提示先到管理端扫码登录。账号没有版权或会员权益、只返回试听地址、登录失效、下载超限和接口超时都会返回明确错误，不会静默替换成其他音源。

## 缓存与播放链

远程音频在服务端下载到受容量和有效期限制的缓存目录，再复用现有的音频解码、Opus/PCM 转换和设备下发链。这样不需要修改 ESP32 设备协议。缓存下载限制单文件最大 40 MB，响应必须是音频类型，并使用临时文件完成后原子替换，避免播放未下载完整的文件。下载开始前会按响应声明大小预留容量，接口没有声明大小时按单文件上限预留，因此并发临时文件也计入容量边界。已保存的播放队列文件会在播放期间受缓存引用保护；如果缓存空间全部被待播放文件占用，新歌曲会明确报错而不会突破容量上限。队列在总准备期限前完成的歌曲会按原顺序播放，超时或无权益歌曲的数量会在开场提示中明确说明。
